# Alpha Atlas：因子研究地图的逻辑框架

**从“给因子分类”，走向“建立研究空间”；用实验填充地图，用因子承载成果，用行为数据检验是否发现了新信息，再用未解决的问题引导下一轮研究。**

下面把这条逻辑展开。

**一、先明确地图的目标**

地图有两个用途：

1. **组织因子库**：理解每个因子测量什么、如何实现、与其他因子是否重复。
2. **引导大模型研究**：知道哪些方向已经探索、探索到什么程度、还有哪些问题值得继续研究。

第二个用途决定了：地图必须能够表示**尚未产生因子的区域**。所以，地图不能只是已有因子的散点图或聚类图。

**二、一个因子需要三个独立但关联的描述空间**

| 空间 | 回答的问题 | 内容 |
|---|---|---|
| **语义空间** | 想测量什么？ | 概念归属、市场现象、经济机制假设 |
| **实现空间** | 具体怎样测量？ | DSL、输入字段、算子结构、参数、频率、计算口径 |
| **行为空间** | 实际表现怎样？ | 信号分布、持续性、因子相关性、IC、稳定性、组合增量 |

三者通过因子版本 ID 关联，但不能相互替代。

例如，使用 `TS_ZSCORE` 是计算事实，不足以证明它属于均值回归；两个因子都叫“趋势”，也不保证输出相似；两个因子 IC 相近，更不代表它们提供相同信息。

**三、语义分类采用“大类 → 表征方式 → 具体定义”**

以趋势为例：

```text
趋势
├─ 均线结构
│  ├─ 多空排列
│  └─ 均线发散
├─ 高低点结构
│  ├─ 高点抬升
│  └─ 高低点同步抬升
└─ 价格位移
   ├─ 累计收益率
   └─ 回归斜率
```

这三个层级分别表示：

- **大类**：测量市场的哪个属性。
- **表征方式**：使用哪种证据观察这个属性。
- **具体定义**：如何描述这一现象的测量规则。

精确窗口、SMA／EMA、拐点算法等进入实现空间，不必每改一个参数就创建一个概念。

同时，允许一个因子具有主概念和辅助概念。例如“放量突破”关联趋势与成交参与度，并记录“量能确认突破”的组合关系。

**四、把“测量现象”与“预测假设”分开**

“过去一段时间放量上涨”描述当前现象。

“之后会继续上涨”或“之后容易反转”是两个不同的预测假设。

因此，一个完整的研究命题需要包含：

```text
测量现象＋预测目标与期限＋机制假设＋适用或失效条件
```

语义说明还要记录来源和证据状态，区分公式提取、规则推断、Agent 提议和实验支持。整体 IC 为正，并不能直接证明某个经济解释成立。

**五、地图的基本单位从“因子”提升为“研究区域与命题”**

这是整套设计最关键的一步。

如果只对已有因子聚类，地图只能告诉我们“找到了什么”，无法表示“还没研究什么”。

因此，建立以下对象关系：

```text
研究区域
└─ 研究命题
   └─ 实验
      ├─ 产生因子
      └─ 产生支持、反对或不确定的证据
```

区域可以没有因子；实验可以没有成功成果；失败实验仍然增加对区域的认识。一个实验或因子也可以关联多个命题。

例如，“成交量是否能提升高低点抬升信号的可靠性”，在写出任何 DSL 前就可以作为待研究命题存在。

**六、“大陆、区域、地块”负责导航，行为群落负责验证**

为了让大模型获得稳定的研究地址，地图主结构按研究问题组织：

| 地图层级 | 含义 | 示例 |
|---|---|---|
| **大陆** | 市场属性 | 趋势与方向 |
| **区域** | 表征方式 | 高低点结构 |
| **地块** | 可检验的具体命题 | 放量确认能否提升高低点同步抬升的预测能力 |

已有因子的行为聚类作为覆盖图层，回答：

> 这些看起来不同的研究方向，实际提供了多少不同的信息？

这样能识别两种重要情况：

- **概念覆盖广、行为重复高**：开发了多个区域，但成果主要是同一种信号。
- **概念相近、行为差异大**：同一区域内出现了值得分别保留的不同信号。

因此，研究地图与行为地图共享对象、相互联动，不必强行合成一个距离分数。

**七、开发程度用三个维度描述，不用因子数量代替**

| 维度 | 核心问题 |
|---|---|
| **探索覆盖** | 尝试过哪些测量路线、假设和条件？哪些还没试？ |
| **证据状态** | 命题尚未检验、证据不足、获得支持，还是存在冲突？ |
| **成果价值** | 是否产生合格因子、独立信号或可验证的组合增量？ |

由此得到两个重要原则：

**没有成功因子，不代表没有开发。**  
**存在大量参数变体，不代表充分探索。**

负面结论必须限定范围：某些实现和条件下失败，不等于整个区域永远无效。

**八、行为结果必须带实验范围**

行为不是因子永久不变的坐标，而是条件化的观测：

```text
数据快照 × 计算口径 × 评估区间 × 目标与期限 × 指标定义
```

并且需要区分：

- 因子相关性：因子与因子之间的关系。
- IC：因子与预测目标之间的关系。
- 组合增量：因子加入指定基准组合后的实验结果。

地图展示这些结果时，要保留条件和来源，才能避免把不同实验口径混在一起。

**九、给大模型的输出应是“研究前沿”，而不只是空白区域**

每个区域应能整理出一张研究卡：

```text
已经知道什么
依据哪些实验知道
哪些路线已经失败或高度重复
还有什么关键问题不确定
下一步哪个实验最能解决问题
实验的对照与判断标准是什么
```

研究优先级综合考虑问题价值、不确定性、潜在新增信息和实验成本。空白区域只是候选方向之一；已有结果互相矛盾的区域，也可能值得优先研究。

**十、最终形成持续更新的闭环**

```text
建立研究空间
    ↓
识别未决问题，选择研究命题
    ↓
设计 DSL 与对照实验
    ↓
记录因子、行为结果和证据
    ↓
更新区域的覆盖、认知与成果状态
    ↓
通过行为关系检查冗余与新增信息
    ↓
生成下一轮研究指引
```

整套方案的核心可以概括为：

**概念提供地址，DSL 提供实现，实验提供证据，行为揭示信息结构，因子承载成果，未决问题决定下一步方向。**
