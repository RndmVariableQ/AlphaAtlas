# 知识地图设计

本文描述研究设想；当前实现状态见[方法目录](methods/README.md)。
项目目标是在有限实验预算下，积累可验证、非冗余的因子与市场认识。

## 基本原则

1. **假说可检验。** 写清观测现象、预测目标与期限、机制解释、适用条件和反证标准。
2. **表示可追溯。** 语义说明、计算表达式和行为观测关联到同一因子及其具体实验。
3. **证据有边界。** 相关性不证明经济机制；失败只否定已检验的实现与条件。
4. **导航服务实验。** 每个地图对象都应帮助定位已有证据或选择下一步实验。
5. **新增信息可衡量。** 公式变化、命名变化或新增区域都不能直接当作有效发现。

## 三种表示

| 表示 | 回答的问题 | 内容 |
| --- | --- | --- |
| 语义 | 测量什么，为什么可能有效？ | 市场现象、机制假说、来源、证据状态 |
| 计算结构 | 如何计算与复现？ | DSL、字段、算子、窗口、频率及依赖 |
| 实证行为 | 在什么条件下观察到了什么？ | IC、覆盖、相关性及已实现的共享诊断 |

三者分别保留，不预设必须合成一个距离。相同机制可能产生不同行为，不同解释也可能
产生同一信号。行为观测必须携带数据快照、评价区间、目标、口径与来源；不能作为永久坐标。

“放量上涨”是测量现象，“随后延续”与“随后反转”是不同预测假说。
语义来源区分人工定义、公式推断、模型提议与实验支持，不能把事后解释直接当作结论。

## 地图与导航

```text
研究区域 → 可检验命题 → 实验 → 因子与证据 → 下一步问题
```

区域按市场属性与表征方式组织，允许没有因子；一个因子或实验可以关联多个命题。
窗口等实现参数放在计算结构中，不为每个参数变体创建新概念。
行为关系用于检查信号冗余，探索记录保留成功、失败、不确定性和成本。

每个区域应能回答：已经知道什么、依据哪些实验、哪些路线重复或失败、仍有哪些问题、
下一次实验如何判定。空白与结论冲突都可能值得研究，空白本身不意味着存在 alpha。

探索优先级拟综合预测质量、新增信息、不确定性与实验成本。评价覆盖时，应先固定独立于
被比较方法的分类口径，避免通过不断创建区域虚增覆盖；具体奖励尚需实验确定。

## 当前基础与研究顺序

已具备数据、DSL、评估、因子库、冻结 OOS 与多方法接入；`atlas` 是区域 UCB 原型。
完整联合表示、自动生成研究命题、学习式地图与知识层搜索尚未实现。

| 下一步 | 可验收的结果 |
| --- | --- |
| 固定问题与地图表示 | 用已有因子和失败实验说明三种表示及证据关系，避免新增重复身份 |
| 定义知识增量 | 固定覆盖和冗余评价，检查参数变体、语义改名是否虚增成绩 |
| 实现导航策略 | 复用公共 session，在相同条件下比较有／无地图导航 |
| 检验探索价值 | 多 seed 与机制消融，报告积累曲线、成本及冻结库 OOS |

每一步先提出当前需要验证的问题，再选择最小实现。动态市场推演、交易执行与 AGI 系统
不属于当前实现承诺。[概念路线图](figures/alpha-atlas-concept-roadmap-v2.png)仅表达研究愿景。
