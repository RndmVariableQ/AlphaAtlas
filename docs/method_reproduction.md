# 方法复现与统一比较规范

更新日期：2026-09-12。适用于所有已有方法、外部复现和后续新增方法。
这是接入与验收规范；文中待补能力不表示代码已经实现。
各方法状态见 [方法清单](methods_to_compare.md)，首个按本规范规划的外部方法见
[MCTS-LLM 复现方案](mcts_llm.md)。

## 1. 复现目标与来源优先级

本项目默认做**统一实验环境下的搜索算法适配**：保留方法的核心搜索机制，使用
Alpha Atlas 的数据、表达式执行、评估与准入，比较静态有效非冗余因子的积累效率。
这不等于重现原论文的数据集、收益表或组合策略。

来源冲突按以下顺序处理：

1. 本项目的数据隔离、因果性、公共权限、预算和冻结规则是接入硬边界。
2. 固定版本的论文正文、附录和勘误定义要复现的算法。
3. 与论文对应的作者代码用于补足实现细节；代码与论文冲突时必须写明取舍。
4. 第三方复现仅作实现参考；README、默认参数和代码注释都不能单独证明论文一致性。
5. 仍未定义的边界采用最小、可测试的本地约定，在方法说明中标为本地选择。

每种方法说明须固定论文版本、仓库分支与完整 commit，并列出实际参考的文件／函数。
只移植必要逻辑；复制代码或提示词时核对许可证并保留所需署名，不复制环境、数据和凭据。
本项目配置与实现继续使用已有冻结校验，不另加来源或检查点哈希体系。

## 2. 模块归属

| 模块 | 统一使用 Alpha Atlas | 方法保留或参考上游的部分 |
| --- | --- | --- |
| 数据与标签 | asset adapter、MarketData、PIT、split、预热、标签边界 | 不带入上游数据加载器、Qlib 数据或标签生成代码 |
| 字段与频率 | 同组实验相同字段权限和频率语义；期货真实合约／连续段隔离 | 根据允许输入形成市场假设；不暗中扩大字段权限 |
| 表达式与算子 | 现有 DSL、AST、编译器、算子注册表、null／窗口／身份规则 | 候选生成分布、结构偏好、参数搜索与方法内复杂度正则 |
| 研究工具 | SearchSession 的 context、库查询和公共反馈 | 查询时机、检索排序、few-shot 选择；不复制工具实现 |
| 原始数值指标 | 公共 evaluator 计算 train/val 报告及批准的共享诊断 | 从报告计算奖励、相对排名和搜索优先级 |
| 正式因子库 | 公共准入、相关去重、first accepted wins、原子提交 | 树、图、种群、工作池和搜索记忆；不能自行正式入库 |
| 搜索控制 | runner 的候选提交、全局尝试上限、冻结与恢复 | 选择、扩展、变异、交叉、回传、局部预算分配和重启 |
| LLM 与 embedding | 复用现有模型客户端、外部凭据读取、用量与失败记录 | 角色分工、推理阶段、方法提示词和必要 embedding 策略 |
| 持久化 | 现有 run 配置、原子 trial、方法状态、checkpoint | 保存树／图／种群、RNG、已完成模型阶段和待反馈状态 |
| 比较与 OOS | 统一报告、冻结成员、统一 test 评估 | 上游收益表仅作背景；方法内奖励不能作为跨方法成绩 |

源码入口：[contracts.py](../src/alpha_atlas/contracts.py)、
[session.py](../src/alpha_atlas/session.py)、[runner.py](../src/alpha_atlas/runner.py)、
[evaluation.py](../src/alpha_atlas/evaluation.py)、
[library.py](../src/alpha_atlas/library.py)、[模型客户端](../src/alpha_atlas/methods/models.py)。

同名算子不能直接认作等价。接入说明须核对时序／截面作用域、返回值、窗口单位、
样本方差约定、除零、缺失值和边界。语义相同才映射别名；不等价则明确标为替换。
缺少必要算子时，先通过现有公共算子机制补足、测试并更新目录，不能运行上游隐藏执行器。
主比较组使用相同冻结算子能力；代码生成或运行内算子注册需要单独标识实验条件。
平台没有窗口或累计历史上限；方法自己的有限采样集合须披露，不能升级为公共限制。

## 3. 公共信息与方法自主性

模型可见 `get_context` 由 `SearchSession.query` 分发到 `research_context`，一次返回
asset、frequency、target、metric、fields、完整 operators、expression_rules、
evaluation_rules、reference_library。日期、fold、universe、路径、run/snapshot ID
不进入 context 或提示词。平台内部 `SearchContext` 含预算用于调度，不能直接序列化给 LLM。
`remaining_attempts` 只出现在公共评估结果中，不进入固定提示词或只读查询结果。

所有方法复用 `get_context`、`library_search`、`library_get`、`library_list`、
`library_stats`；候选由 runner 提交公共 `evaluate`。工具语义相同不要求每种方法
采用相同的对话封装、查询次数或搜索策略。共同工具示例见 [研究工具说明](react_tools.md)。

允许不同奖励，不强行把全部方法改成同一个 IC 奖励：奖励本身可能就是待复现机制。
每个奖励项必须标出公式、方向、范围、使用的 split、参照池、更新时点、并列和缺失规则。
训练驱动方法可以忽略 val；所有方法最多获得同一公共 train/val 权限，不能访问 test。
LLM 的过拟合判断或语义一致性判断是方法评分，不是已测得的泛化指标。

需要因子间统计时复用现有 `SearchSession.factor_correlations`，仅处理本次运行已评估
身份并返回训练统计，不返回行情、因子数组或标签。它是方法内部公共能力，当前不属于
上述五个模型 JSON 查询工具。新增数值诊断必须位于公共评估层，提供同一权限和同一定义；
方法只决定是否使用。不可为了某个方法额外开放 MarketData 面板或新建专属回测接口。

当前公共报告已有 train/val IC、方向、覆盖率和准入相关信息；`benchmark.toml` 的
`search_diagnostics = "icir_turnover_v1"` 为所有方法开启共享训练 ICIR／持仓换手诊断，
具体数值语义见 [MCTS-LLM 的共享诊断定义](mcts_llm.md)。设为空字符串统一关闭。
诊断只用于反馈，原有主指标与准入不变。不能从单个汇总 IC 推造 ICIR，
也不能把结构距离命名为数值相关性。
缺失的核心反馈必须先补公共定义与测试；删维度的版本须单独标为简化适配或消融。
补诊断只增加明确需要的报告内容，不顺便扩建组合回测系统。

## 4. 因子库、参考信息与初始化

正式库按 `(asset, dataset, universe, fold, method, seed, run_id)` 隔离。
方法工作池可保留未入库候选及失败历史，复用现有 factor ID；工作池成员数不计入成绩。
工作池门槛、搜索奖励不能覆盖正式库的质量／覆盖率／相关去重门槛。

参考库开关统一在 `configs/benchmark.toml`，进入已有 rules 冻结校验。
参考定义没有当前实验成绩，不免费准入。上游 alpha zoo、预先挑好的有效因子、
带绩效的 few-shot 示例不能作为方法私有优势直接导入。若确需引入外部定义，先登记
公共参考来源、允许范围和实验条件，对同组方法一致开放，重新评估才产生本次运行证据。
方法自带的初始模板可以保留，但须披露来源、数量和搜索偏好，每个实际评估都计预算。

## 5. 预算、失败与恢复

主预算是已提交的候选尝试数，沿用现有 `max_attempts`／run attempts 规则。
初始化、根节点、参数试探、重复、非法表达式、质量拒绝和缓存命中均按每个实际提交
扣一次。一个 LLM 回复给出多个待测公式或参数组合，就有多次尝试；不能只记录赢家。
不增加免费隐藏预评估，恢复已提交 trial 不再次扣费。

只读查询、纯语法检查、格式纠正和摘要不扣评估预算，实际模型调用及时间仍计成本。
每个方法须明确有限的查询／纠正停止条件，以及耗尽后是记录生成失败还是使运行失败；
沿用其已有方法阶段和失败记录，不为本规范另造通用失败调度框架。
服务错误、解析错误、数值不可定义必须如实记录，不能用固定“中等质量”、随机分或
假公式继续冒充成功搜索。未知统计不能当作零相关；模型用量未知不能记为零。

方法可在全局剩余额度内分配局部树预算、种群轮次或多次重启，不能自行增加全局额度。
局部“奖励预算”是分配机会，不是免费尝试。树耗尽可以重开一棵树；全局耗尽停止生成。
内部迭代数与实际尝试数分别记录，不能用相同迭代数声称预算相同。

接入优先复用 `ask/tell`、`dump_state/load_state`、`set_session` 和既有阶段保存方式。
`tell` 不调用外部模型；如需评估后模型阶段，必须放在可恢复的生成阶段，并确保最后
一个候选也完成必要方法更新。保存已有响应后恢复不重发；已提交 trial 不重复回传或入库。
外部请求已发送而响应尚未保存的中断仍可能重发，须记录未知用量，不声称端到端恰好一次。
不新增状态账本、检查点校验和、缓存指纹或全文件强制重扫；旧运行产物保留。

## 6. 比较条件与报告

同组比较冻结相同数据快照、资产／频率、目标、fold、字段、算子能力、评估与准入规则、
参考库开关、尝试预算和预先选定的 seed 集合。LLM 方法的主比较尽量使用同一个基础
Chat 模型与服务版本，统一可比的资源条件；角色数、调用次数、必要 embedding 和方法
温度策略保留并披露。原论文模型设置可以另列复现实验，不与受控主组混为一谈。
现有 ReAct／AlphaPROBE 默认模型不同，默认配置不是已对齐的正式比较配置。

报告至少包含：有效非冗余成员数随尝试数的曲线，重复／非法／质量／相关拒绝比例，
每个新增成员的尝试与实际成本，以及冻结成员的 OOS IC。补充时间轴和模型用量轴，
记录初始化、检索、修复、摘要、过拟合评分、embedding 的请求和 token 成本。
没有新增成员时单位成本记为不可定义；未提供的 token／费用标未知，不伪造零值。
当前没有 token 或总活动时间硬上限，不能把日志中的用量统计表述为已实施的硬预算。

共享 HTTPModels 对 Chat（包括摘要／风险评分）及 embedding 请求执行相同的有限重试：
连接错误、超时、响应流未收到完成标记，以及 HTTP 408／429／500／502／503／504，
最多额外重试 3 次，分别等待 1／2／4 秒。其他 HTTP 错误、上下文超限和无效响应格式
直接报错，方法自己的格式纠正／上下文处理流程仍按原定义执行；Ctrl+C 不自动重试。
每次重试原请求，失败流的文本不会拼入成功回复或用于评估，终端明确显示重试分界。
重试前通过现有方法检查点累计请求数，失败请求的 token 用量保留为 unknown；
只有完整成功响应的已知 token 计入统计。重试不扣候选评估预算、不新增 trial。
全部重试失败后沿用原有中断与恢复流程，已提交 trial 和已保存完整模型响应不重做。
这属于公共客户端的本地行为，不声称源论文采用了相同重试策略；配置冻结校验照常执行。
源码指纹仅保留来源记录，不比较当前源码或依赖锁文件来阻止续跑、OOS 或模型复用。

相同评估器不代表相同搜索空间。固定模板与完整 DSL 的结果标为整体系统比较；要归因
某个搜索机制，需另作相同生成器、反馈和资源条件下的消融。不能用当前符号 `mcts`
对照直接证明 LLM-MCTS 的树策略优劣，也不为“公平”静默改写旧基线的算法。

先冻结全部开发决策与运行，再查看 test；不按 test 选模型、种子、参数、方向或成员。
两个现有 fold 的时间区间有交叠，不宣称相互独立的最终盲测；具体边界沿用 README。
现已提供独立的公共 [model 评估](model.md)：冻结全库作为特征，比较 linear 与 LightGBM。
这不是原论文组合实验复现；首版固定超参数，训练和预处理仅使用 train，val 作开发报告，
保存模型后显式评估 test。所有方法使用相同模型配置与数值规则，不向搜索返回 test。
MLP、top-k 选择及交易收益评估尚未接入。

| ReAct | AgentScope 单模型工具循环（支持单轮多工具）、反馈和工作记忆 | 自建 LLM 基线；专项检查工具批次、反馈和 AgentScope 上下文压缩 |
| MCTS-LLM | 公式节点、虚拟动作、定向改进、相对排名、max 回传、FSA | 已有五维适配；共享持仓定义与论文／第三方差异见专项说明，待真实模型效果验证 |
| AlphaAgent | 假设生成、原创性、语义一致性、复杂度正则 | 待接入；锁定论文对应分支，区分方法正则与公共准入 |
| CogAlpha | 多角色检查／修复、代码变异与交叉 | 仅公开提示词；先界定 DSL 转译损失，不能称完整源码复现 |

## 8. 每个方法统一交付与验收

方法说明使用同一顺序：来源及版本 → 保留机制 → 模块归属／差异 → 奖励与反馈映射 →
配置与预算 → 失败与恢复 → 验证与当前状态。用普通 Markdown 表列
“原定义／上游实现／本地选择／影响／测试”，不另建机器可读注册中心。

状态分别陈述，不能互相替代：

- 待接入／规范已定：只有设计，无可运行实现。
- 基线或原型：可运行的有限实现，不冒用论文方法身份。
- 算法适配：列出的核心机制通过数值、边界、失败及恢复测试，所有偏离均披露。
- 真实模型实验已验证：另列模型、配置、实际运行和结果；模拟模型测试不满足此项。
- 原论文实验复现：还须对齐原数据、实验协议和结果验证；本项目的统一适配不默认达到。

实现验收要求：小例手算验证关键公式，模拟模型验证生成与工具流程，合成 MarketData
验证时间／合约／train-val-test 隔离，边界测试覆盖空池、并列、不可定义数值、预算
尾部及中断恢复。测试不使用真实凭据或供应商 API。新增公共指标须做跨方法同输入同结果
回归检查；源码映射须有算子数值／边界证据，不能只看函数名或跑通示例。
修改同步文档并运行 `pwsh -File scripts/check.ps1`；真实模型实验与论文成绩另行记录。
