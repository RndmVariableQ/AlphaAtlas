# 方法复现与统一比较规范

方法目录见 [methods/](methods/README.md)，数值与数据见[实验规范](research_protocol.md)，
开发原则见[开发指南](development.md)。本项目比较统一环境下的搜索算法适配，不默认复现论文收益。

## 来源与边界

- 论文固定版本定义算法；作者代码补充实现，第三方实现仅作参考。冲突和未定义细节写明本地选择。
- 方法说明记录论文、来源 commit、实际参考模块与许可证；移植内容保留必要署名。
- 保留核心搜索机制和奖励组合；替换反馈、缩减维度或用模板代替模型，须标为适配或消融。
- 平台边界不可绕过：方法不直接读数据、标签或供应商，不自建数值执行器、准入或工具实现。

| 公共平台负责 | 方法负责 |
| --- | --- |
| 数据、目标、PIT、split、字段与频率语义 | 假说、候选生成分布与表达式结构偏好 |
| DSL、算子、数值指标和共享诊断 | 选择、变异、树／图／种群及奖励组合 |
| SearchSession、预算、正式准入、原子 trial | 查询策略、few-shot、局部搜索预算与重启 |
| 模型客户端、冻结、恢复、报告与 OOS | 角色、提示词、生成阶段和方法状态 |

同名算子先核对数值与边界再映射；缺少能力时补公共实现，不引入方法专属数据权限。
原始指标与奖励分开记录。奖励须说明公式、方向、split、参照池、更新时点、并列与缺失规则。

## 公共信息与初始化

所有方法复用[研究工具](research_tools.md)；工具权限一致不要求相同查询次数或对话封装。
模型仅见稳定研究元数据与 train/val 反馈；日期、fold、universe、运行／快照 ID 留在平台内部。
remaining_attempts 仅放在评估结果中，平台内部保留预算控制。

参考库由 `configs/benchmark.toml` 统一开放或关闭，并进入已有冻结校验。
无绩效参考定义必须重新评估才可正式准入；不得私自导入带绩效因子作为方法优势。
显式种子要记录来源、数量及初始化成本。工作池和失败历史复用已有因子 ID，不计为正式成员。

## 预算失败与恢复

- 默认预算按候选尝试数。初始化、重复、非法、缓存命中及质量拒绝，每次实际提交都扣一次。
  一个回复中的多个候选逐个计数；不允许免费隐藏预评估或仅记录赢家。
- 只读查询、语法预检、格式纠正和摘要不扣评估预算，实际模型请求与耗时仍计成本。
  局部预算受全局上限约束；当前没有 token／总活动时间硬预算。
- 失败显式记录，不用随机／固定质量分掩盖未知测量。缺少核心反馈不能静默减少奖励维度。
  每种方法设置有界查询／修复次数，并说明耗尽后是生成失败 trial 还是运行失败。
- 复用 `ask/tell`、`set_session`、`dump_state/load_state` 和现有阶段检查点，保存 RNG、
  图／树／种群、待反馈状态与已完成模型阶段。tell 不请求外部模型，状态仅允许 JSON。
- 已提交 trial 复用原反馈，不重评、重复准入或扣费；尚未提交的计算可重做。
  已保存模型响应不重发，请求已发但尚未保存的中断可能重发，用量记为 unknown。
- 沿用配置、数据和冻结校验；源码／依赖锁文件指纹仅记录来源，不阻止续跑、OOS 或模型复用。
  不另建状态账本、检查点／缓存哈希、重复源码指纹或全文件强制校验。

公共 HTTP 客户端对连接错误、超时、流未完成，以及 HTTP 408/429/500/502/503/504，
最多额外重试 3 次，等待 1/2/4 秒。其他 HTTP 错误、上下文超限与格式错误交给方法处理。
Ctrl+C 不重试；部分回复不用于候选。每次重试计请求数，未知用量不记为零，不新增 trial。

## 公平比较

同组固定数据快照、资产池、fold、字段、算子能力、参考库、初始化条件、准入与预算；
记录模型／服务、seed 和方法参数。搜索空间不同只能报告系统比较，不能直接归因为搜索机制。

报告包含尝试／实际评估／入库数、拒绝与重复比例、因子积累曲线、时间、模型请求和已知 token，
以及冻结全库 OOS；未知成本单独标注，没有新增成员时单位成本不可定义。
方法自行创建的区域不能直接计为覆盖成功，覆盖标准须独立固定。

受控消融仅改变被检验机制。先冻结全部开发决策与运行再看 test，不按 test 挑种子、参数或因子。
下游模型统一遵循 [model](model.md)，其训练范围和报告不混入搜索反馈。

## 交付与验收

每个方法只维护一份说明：来源 → 核心机制 → 本地差异 → 配置／失败／恢复 → 验证。
新增入口同步更新[方法目录](methods/README.md)，真实实验结果只写入[实验记录](records/experiments.md)。

验收覆盖：独立手算奖励与选择、空池和并列、非法／缺失反馈、预算尾部、重复身份、
模型阶段与 trial 边界中断恢复、配置冻结和 OOS 隔离。自动化测试不访问真实模型或供应商。
`pwsh -File scripts/check.ps1` 通过后，真实模型接口与市场实验另行验证。
基线、协议接入、算法适配、市场实验和论文复现分别陈述，不能相互替代。
