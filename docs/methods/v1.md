多组持续并发的本地适配见 [V1 异步研究](v1_async.md)，使用独立 `v1_async` 入口。

入口 `--method v1`，实现标识 `atlas_explorer_v1`。仅更新 Atlas Explorer；
Analyst、Miner、候选反馈与 Metropolis 选择复用 [annealing](annealing.md)。
旧 `--method annealing` 仍可运行，已有运行不改名、不切换方法。

## 提示词与周期选择

提示词只说明角色任务、证据用法和输出协议。Explorer 提出问题和竞争解释，说明证据缺口
及区分解释的检验；仅改变名字、窗口、符号或周期不足以构成新方向。Analyst 确定字段、
特征周期、窗口、对照和阈值，Miner 按计划实现候选并使用逐次反馈。基础字段示例、基础频率
和可用高周期从公共 context 动态提供；不按资产硬编码周期，不设置高周期配额。
Explorer 提案须能用当前 context 中的字段、算子和评估反馈回答，并在 `review.readiness`
说明现有测量如何检验预测；Analyst 设计测量路线，Miner 实现表达式，平台负责评估。
该约束通过提示词表达，不增加提案初筛、评分门槛或新的执行接口。
研究覆盖稀疏时优先未测机制和信息来源，覆盖扩展后再回访有前景的方向。差异性评分中，
参数或条件变体为 1，已知机制内的新预测为 3，未测机制或信息来源为 5。Explorer 根据
已有地图与历史记录判断覆盖，不新增阶段字段、预算输入或配额；评分权重与选择算法不变。
异步包装只补充空闲计划名额的说明，探索与回访偏好统一使用主提示词。

平台评分选择、Metropolis 调度和准入流程不再重复写入角色提示；主提示、收敛提醒、
不足澄清与异步包装也不重复说明同一规则。Train/Val 方向、完整计划证据与 trial 引用语义
仍保留。新回复的批次范围为二至四个；检查点中已校验的旧批次直接复用，不重写历史回复。
正在运行的进程保留启动时已加载的代码；重启或恢复后新请求使用当前提示词。

## 一轮研究

1. Explorer 收到原退火流程的 breadth/depth、当前 Region、完整 run 内地图和已研究方向。
   地图沿用原配对主指标统计；支持／反向样例保留 trial 索引与指标。
   `atlas.plan_results` 自动展开最近完成计划和地图样例所属的进行中计划，提供原始 plan
   和全部已提交候选，包括未入库、覆盖不足和编译失败。近期范围为串行最近一组、异步
   最近 `parallel_plans` 组；同计划只展示一次。较早已完成计划保留在完整历史索引中，
   提案引用时通过现有 `sources` 补全整组并确认，不因被地图采样就自动展开全部旧计划。
   `blocked_plans` 仅携带计划编号、区域、方向和阻塞原因，不重复附带计划全文。
   记录按已有 `research_plan_index` 关联，`annealing_result` 只标记执行结束，不代表所有设计检验
   均已完成。活动计划只展示已提交记录，标为未完成；不从入库成员反推全部研究结果。
2. 必要时通过现有五个 SearchSession 只读工具查库，支持公共接口的关键词 AND、分页和
   run/reference 范围。`library_search` 与 `library_get` 的完整结果可引用；
   `library_list`、`library_stats` 只提供索引／统计，不能代替完整测量证据。
   计划正文中 trial 的 `candidate.expression` 与 `evaluation` 是完整证据；`trial:N` 是引用，
   不可作为 `library_get` 的 `factor_id`。后者仅查询已入库成员，返回 null 不表示地图中的
   未入库试验缺少定义；实际查询与失败只能依据本轮已保存的查询结果，不能从方向描述推断。
3. Explorer 一次提交二至四个完整方向。每条包含问题、机制假说、条件、可观测预测、竞争解释、
   引用，以及已有 Region 或现有 continent 下的新 Region。四项评分均为 1–5 整数并须
   给出理由：研究价值 30%、实验判别价值 30%、研究区别 20%、可执行性 20%。
4. 服务端计算百分制分数 `sum(score * weight) / 5`，选择最高项；并列保留提交顺序，
   不消耗退火 RNG。只有选中方向的新 Region 才注册。整批方向先全部校验通过，
   再交接选中项，避免格式修复留下部分 Region。
5. 原 Analyst 接收选中问题、完整 Proposal，以及引用的整组计划和查库证据。
   `sources` 保留提案的引用编号；其 `value` 为该 trial 所属计划、所有实际候选与反馈。
   同计划多个引用共用一份正文，模型原始 `references` 不改写。Miner 按原流程
   逐条提交候选。Region reward、温度、接受概率、每计划候选数和准入全部沿用退火方法。
   四项选题评分只决定本轮研究哪个方向，不替代候选评估或 Region reward。

方向可以是新问题，也可以是对已完成方向的证据驱动回访。Explorer 使用既有提案字段说明
尚未回答的问题、依据或缺失测量，以及下一步可证伪检验；可针对不充分验证、竞争解释、
实现／覆盖问题、未测条件或交互继续研究。少量因子试验不等于整个机制已被穷尽。
`previous_directions` 是全部已结束计划的事实索引，不是待执行队列或永久排除列表；并发时仅
`active_proposals` 表示尚未完成的计划，过去未选中的备选方向不排队。breadth/depth 是预算分配偏好，
没有可信新机制时仍可选择合理回访。批内提案须有实质差异，不并发重复活动计划的具体问题
和预测；不以改名或无证据依据的窗口／符号／频率变化伪装新方向，不增补数据或算子权限。

Explorer、Analyst、Miner 都能使用同一组五个公共只读查询工具；Analyst 与 Miner 的查询
使用 AlphaPROBE 的 `queries` JSON 批次格式，每轮最多 16 个请求、每阶段最多 8 轮。
Miner 的阶段指一个候选，计划字段和研究方向仍由上游约束；公共查询不改变这些权限。
查询与恢复的具体规则见 [annealing](annealing.md)，不开放额外评估或算子开发工具。
Analyst／Miner 不可执行时使用[计划阻塞与交接](annealing.md#计划阻塞与交接)；
Explorer 读取 `atlas.blocked_plans` 后换题，或提出解决缺失能力的新检验。

重复校验拦截仅改标题、其余研究内容相同的批内提案；机制是否实质不同仍依靠提示与研究审阅，
不宣称程序能判定自然语言语义等价。完整提案批次和被引用的库结果保存在原方法状态及本轮
最后一条 `factor_trial_records` 记录内；未选方向是本轮备选，不建立待执行队列或跨 run Proposal 数据库。
新索引每计划保留一条，即使标题相同也保留不同轮次及其结果。旧的标题列表快照仍沿用原有
`(region_id, direction)` 展示去重，不改已保存输入；不合并语义改写或回写历史 trial。

## 按计划读取历史

索引按 `factor_trial_records` 中的计划归属和原子 trial 的事实派生，包含 `research_plan_index`、
区域、原方向、全部 `factor_trial_refs`、成功测量数、拒绝原因与入库数；不另存记忆表。
完整正文从相同 `research_plan_index` 的记录取得原 plan，再按 `factor_trial_index` 读取
全部 trial 反馈。公式、指标和准入裁决只从原子 trial 取得，不使用旧 step 的副本。
沿用 factor ID，不按相邻编号、当前计划长度或相同标题拼接；读取与恢复见
[计划记录与原子 trial](annealing.md)。
公式、状态、Train/Val 原始指标、方向、覆盖和准入裁决保留；OOS、动态预算不进入该视图。
区域 Train 摘要取绝对值，正文中的 Train 指标保留原符号，Val 仍是平台已定向的数值。

草稿可以引用索引中尚未展开的 `trial:N` 作为查证线索。服务端先校验整批结构、区域、评分、
重复及引用范围，再将同计划完整正文写入该条回复的既有 `sources`，要求下一条回复读取后
确认或修改提案；此前不注册区域、不创建 Analyst 计划。正文中同组的其他 trial 也成为可用
引用。未知编号仍拒绝，已展示证据不重复补全；这不是 `library_get` 或额外的公共查询工具。
补全与确认沿用原对话上限，实际模型请求计成本，不扣候选预算；最后一轮才补全时仍须停止，
不能自动接受未经确认的草稿。

回访使用现有提案字段说明最近的相关实验、已测内容和下一项可证伪检验。索引尚未核对只能
表示“记录待核对”，不能据此声称“从未测试”；对照的有效 IC 不归给未通过的主项，失败测量
也不自动否定假说。服务端保证证据交接与引用边界，不裁定自然语言机制等价或因果结论。

投影在新建 Explorer 快照时生成。已保存的输入、回复和补全正文沿原检查点恢复，不重发已
保存响应、不重复补全或评估；旧的单条 trial `sources` 与 `recent_trials` 输入仍可读取。
V1 Async 继承同一路径，活动计划继续使用原计划；运行中切换研究策略须披露切换时点。

## 必须保留的本地差异

| 上游能力／规则 | V1 的本地处理 |
| --- | --- |
| `search_atlas` / `read_atlas` 的分页地图 | 保留完整 run 内精简地图注入；不新建公共工具 |
| 因子及所有状态的全局检索 | 复用公共正式库和配置启用的参考库；本 run 未入库证据来自已有 trial |
| `list_proposals` 与持久化待研究方向 | 输入本 run 已研究方向；保存二至四个提案，仅执行当轮选中项 |
| 来源 `kind/id/revision` | trial 使用原索引；库结果使用含研究轮次和请求位置的本地 ref 并保存原始内容 |
| 上游 1m 及大于 5m 的观察建议 | 使用本项目资产原生频率和显式频率 DSL；不改数据或预测期限 |
| 独立 Train/Valid 覆盖与服务端状态 | 保留本平台成功状态及 Valid 覆盖配对统计；不推测缺失 Train 覆盖 |
| 原始 Valid 需按 Train 符号翻转 | 本平台 Valid 已方向化，直接使用；不重复翻转 |
| 探索任务可提交不足报告后结束 | 保存 summary/unresolved；在剩余对话额度内澄清一次，仍无法提供任何方向则显式中止 |
| 外部客户端、存储和任务恢复 | 复用公共 HTTP、原方法检查点、原子 trial、冻结与恢复 |

日期、fold、universe、run/snapshot ID、标签与 OOS 不进入 Explorer 输入；
参考定义不携带当前绩效，不能免费准入。能力说明来自公共 context，不复制上游硬编码字段、
算子目录、供应商访问或预算策略。详见[方法复现规范](../method_reproduction.md)。

## 配置、失败与恢复

`configs/v1.toml` 沿用退火方法的模型、计划长度、温度和候选预算设置。
`max_dialogue_rounds` 默认 40，供 Explorer 的查询/修复和 Analyst 的对话修复分别使用；
Miner 仍使用 `max_formula_repairs`。Explorer 完成 20 次回复后，从第 21 次请求开始持续加入
收敛提醒：提交二至四个方向、评分和引用，或返回 `unresolved` 并说明证据缺口。
JSON 格式和证据读取约定集中在主提示词，终端显示
当前对话次数和提醒状态。第 40 次回复仍会校验、接受合格提案；未形成提案则停止，不再发第 41 次。

查询不扣候选预算，所有模型请求计成本。重复查询、非法引用、未知 Region、缺少评分理由或
少于两个或超过四个方向均显式报错；格式或查询修复耗尽仍使运行失败。提醒由已保存的回复数
推导，恢复不重置轮数。depth 的 `unresolved` 在仍有对话额度时自动转为 breadth：保留原始
报告，在现有回复中标记 `redirected_to_breadth`，将当前探索输入和阶段的模式改为 breadth。
不更改温度、全局活动 Region 或提案评分，不把一个区域缺少能力当作全图已穷尽。
Explorer 比较全图和参考定义，只选择已有字段、算子和工具可执行的方向。

breadth 首次 `unresolved` 在剩余对话额度内获得一次澄清：从最近已完成计划中重新检查
缺失的对照、条件或交互，提交二至四个带判别预测的方向，或说明证据缺口。原 depth 报告
不计作这次 breadth 的澄清；这也适用于旧检查点已保存连续两次 depth 不足的恢复。
仍不足或已无对话额度时，方法返回 `ExplorerUnresolved` 停止信号。runner 将其视为正常
研究提前结束，保存检查点、冻结实际已有因子，并在运行及报告中记录 `search_stop_reason`。
实际提交数、剩余额度和请求成本如实保留，不伪造候选，也不要求耗满预算。
异步补位若基于仍有活动计划的快照，研究不足或对话耗尽时先完成原计划、等待新证据，具体见
[异步失败与恢复](v1_async.md#失败与恢复)；单独的 V1 串行运行仍执行本节停止规则。
澄清复用原回复的错误反馈与对话记录；恢复旧的不足报告也能进入这一步，不重置请求计数。
已在 breadth 保存两次 `unresolved` 的检查点可直接正常冻结，不重发模型请求。
技术错误、非法格式和未形成合法不足报告的对话耗尽仍失败；没有把这些错误转换为完成。

每次请求前保存请求计数，响应保存后才处理，查询结果、修复原因、批次和选中项复用原检查点。
恢复已保存的大型 Explorer 输入时，同样收敛自动展开的旧计划和阻塞正文；完整索引、
地图统计、进行中计划、已校验提案引用的整组证据及对话 `sources` 保留，不重发已保存回复。
原子 trial 与研究计划正文不裁剪，不增加存储或修改检查点格式。
V1 独立校验方法状态版本与配置，旧退火运行沿用原入口恢复；不做检查点迁移。
新默认值不改写历史运行：冻结为 8 轮的旧 run 仍保留原限制，普通续跑不能直接切换为 40 轮。

```bash
uv run atlas run --asset futures --fold fold1 --method v1 --seed 42 --attempts 500
uv run atlas resume artifacts/runs/<run_id>
```
