# V4 Async · 根据已有证据选研究方向

本地方法 `v4_async` 继承 [V3 Async](v3_async.md)。Explorer 在当前可用 Region 中找到
最接近的旧方向，引用可见 trial 或库查询结果，区分已测事实与待解问题，然后提出预测。

| 操作 | 证据与预测 |
| --- | --- |
| expansion | 从未覆盖的可观测机制或已有机制的互补关系提出不同预测。冷启动可用字段映射，参考定义只提供来源 |
| revision | 针对偏离原预测的实测结果或可比证据的冲突，给出竞争解释及可区分的预测 |
| refinement | 围绕已测信号的未知适用条件或库内重叠，指定一个条件或代理量及预期差异 |

操作和理由写入已有的 `review.information_gain`。V4 检查操作前缀、理由非空以及修正和细化的引用；
V3 的引用可见性校验继续生效。事实与理由的语义是否相符由抽样评审判断。评分、排序、Region
可用性、Analyst、Miner、预算和原子 trial 均沿用 V3；恢复使用独立 V4 状态标识。

本轮模型配置来自 B26 初始库的 Haiku V3 版本，fold2、seed 42、每组 500 次。两个配置使用相同
字段、初始库、准入规则和并发。将下例的 haiku55 换为 deepseek 即可选择另一组。

```bash
uv run atlas run --config rq8_zk26_seeded_fold2_v4async_haiku55_500 --attempts 500 --seed 42 --search-only
```

与 V3 比较时按模型和预算节点配对。开发指标为新增入库时的残差 IC 之和 × 100 / 尝试数，
另列入库数、运行耗时、已知 token。选题质量按相同阶段抽取已选提案，隐藏方法和操作标签，
分别判断引用支持事实、预测区别于已有方向、字段足以检验。历史 300 次运行只在共同预算范围内比较。
所有开发决策及搜索冻结后，按固定组合模型比较加入新增因子相对仅初始库的 Test 主 IC 增量。
