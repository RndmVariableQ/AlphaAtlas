# Haiku V3：固定 Val 末品种的配对增量（2026-11-06）

按用户指定，在 Fold2 的 Val 结束时固定品种，再重算 2024–2025 的 Test 指标。
来源为 Haiku 5.5 V3 `61c42b9f7c`，seed 42，B26 初始库，300 次新增尝试。
300 次新增 20 项，共 46 列；预定 200 次前缀新增 13 项，共 39 列。
复用已经保存的 B26 与扩充库预测，模型和原评估产物均未修改。

## 品种范围与计算口径

- Val 截止日为 2023-12-31，最后有观测的交易日为 **2023-12-29**。
  从相同冻结数据快照的 MarketData 读取该日全部品种，共 **79** 个；
  不按当日成交额、Test 表现或模型预测筛选。完整名单与交易所身份见 cohort.json。
- 79 个品种均有原 Train+Val 标签中心。Test 中 74 个有正成交额权重，WMSE 使用
  **2,348,430 行**；JR、LR、PM、RI、ZC 在 Test 没有正权重。
  WH 的配对 IC 未定义，因此两模型、两个节点的 IC 均为 **73 品种、2,326,761 行**。
- 原 86 个 WMSE 品种中的 AD、BZ、LG、L_F、OP、PD、PL、PP_F、PR、PS、PT、V_F
  不在截止日名单。保留品种占原 Test 品种权重的 **96.541135%**。
  全部共同预测中保留 2,467,959 行，其中包含不参与加权的零成交额品种。
- 权重仍为原完整 Test 的品种 √成交额，在保留品种内重新归一化；没有改为 Val 权重。
  B26 与 V3 使用相同品种、样本与权重。相对下降为 `1 − WMSE(V3) / WMSE(B26)`，
  先聚合两组 WMSE，再算比例。
- WMSE 标签沿用原共同 Train+Val 的 1%／99% 裁剪边界
  `[-0.019304276275104854, 0.019190049003133047]`，再减各品种训练期裁剪后标签均值。
  此次评分品种均有训练中心，无需未见品种的零中心规则。IC 沿用原始标签。
- Linear OLS；LightGBM 原生 `min_data_in_leaf=20, lambda_l2=0`，50 轮、学习率 0.05、
  15 叶、最大深度 5。原 Train+Val 5,296,605 行，全部 79 个训练品种与截止日名单一致。
  本次只改变评分品种，不重拟合参数、因子或预处理。

## 300 次主节点

WMSE 下降为相对同口径配对 B26 的百分比，正值表示改善；口径差值单位为百分点。
由于品种范围改变，两个口径的 B26 分母也各自重算，不相互混用。

| 模型 | 原 86 品种 WMSE 下降 | Val 末品种 WMSE 下降 [95% 区间] | 口径变化后的差值 | B26 IC → V3 IC | ΔIC [95% 区间] |
| --- | ---: | --- | ---: | --- | --- |
| Linear | −0.013456% | +0.019690% [−0.037792%, +0.069181%] | +0.033146 个百分点 | 0.013115483 → 0.020628710 | +0.007513 [−0.003540, +0.017509] |
| LightGBM | −0.022965% | +0.011283% [−0.061284%, +0.090284%] | +0.034248 个百分点 | 0.011616349 → 0.016828411 | +0.005212 [−0.008427, +0.020416] |

| 模型 | B26 变换后 WMSE | V3 变换后 WMSE | 原始目标 WMSE 下降 | 2024 变换后 WMSE 下降 | 2025 变换后 WMSE 下降 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Linear | 2.5432135635e-05 | 2.5427128051e-05 | +0.027236% | +0.022404% | +0.016257% |
| LightGBM | 2.5398461117e-05 | 2.5395595307e-05 | +0.020217% | −0.011283% | +0.039054% |

两模型的全期变换后 WMSE 增量均由负转正，支持原结果受到 Val 末未见品种拖累的解释；
这是评分范围改变后的结果，不是模型重训改善。增益很小，WMSE 与 ΔIC 的 95% 区间均跨零。
LightGBM 在 2024 年仍为负增益，不能据此认定稳定优胜，也不能直接与原 86 品种的其他方法排名。

## 核验与复跑

名单先使用截止 Val 的 MarketData 生成并保存，再加载既有 Test 预测。四行结果均使用
按年分层、全市场同步的 20 交易日块、2,000 次重采样，seed 20261102；全部重复有效。
用 NumPy 按逐行「品种权重 / 品种行数」独立复核原始与变换后 WMSE，最大绝对差
6.78e-21；同时复现原 86 品种 WMSE，并确认原 fit.json 与 test.json 逐字节未变。
执行 `pwsh -File scripts/check.ps1`：Ruff、格式、算子目录及 1,349 项离线测试通过，
pytest 用时 132.94 秒，见[检查日志](../../../../artifacts/comparisons/zk26_haiku_v3_val_end_products_20261106/check.log)。

本轮为已查看历史 Test 上、用户指定品种口径的敏感性分析；名单规则不依赖 Test 值，
但规则是在看过原 Test 诊断后提出的，不能将本结果当作预先注册的独立盲测。
