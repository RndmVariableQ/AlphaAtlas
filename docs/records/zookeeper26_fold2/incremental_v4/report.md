## F 配对评估规则
```flow
B26初始库 -> 三方法搜索: 仅 Train/Val
三方法搜索 -> 冻结全部成员: 各 300 次
冻结全部成员 -> 保存所有模型: B26 与扩充组
保存所有模型 -> 统一历史Test
统一历史Test -> 配对指标与区间
```

Train 2019–2021，Val 2022–2023，Test 2024–2025。
最终模型用共同 Train+Val 行拟合。
共同训练行数为 5,296,605。
共同 Test 行数为 2,549,205，覆盖率 99.624%。

加权 MSE 使用 86 个品种、2,429,676 行。
JR、LR、PM、RI、ZC 没有可用正权重，共 119,529 行未进入加权评分。
主 IC 使用共同有效的 80 个品种、2,401,248 行。
L_F、PD、PP_F、PT、V_F 的 B26 预测为常量，WH 的目标为常量。
这些品种的 IC 未定义，不能填为零；各组使用相同排除集合。

B26 按本次共同训练样本重新拟合，不直接沿用旧报告的 IC。
训练裁剪边界也在该共同样本上重估，故与旧单库报告有轻微差异。
目标为未来 12 根 5m 对数收益，沿用合约与 split 边界。

区间按年分层，同步抽取全市场 20 交易日块，共 2,000 次。
预测保持冻结，不重训，也不逐根 5m 独立抽样。
这些是时间波动区间，不替代多 seed 比较。

## H 适用边界
2024–2025 此前已经查看，属于历史诊断留出集。
本轮 Test 没有反馈给搜索，但它不是新的盲测。
固定快照的计算时序经过核验，完整 vintage PIT 尚未认证。
原八字段沿用 Kernel 聚合 5m，曲线保留缺失与代理定义边界。

AlphaSchema 保留 150 个有效奖励计划的代理启动条件。
本轮共有 70 个计划获得有效奖励。
计划选择计数为 {'explore': 183}。
结果应结合该阶段解释，不能代表完整代理引导机制。
本轮只有一个 seed、三种方法，不能推广为所有方法的稳定排名。

初始化与去重实现通过完整离线检查：1,298 项测试。
真实诊断确认原式被身份去重拒绝，倍数变换被数值查重拒绝。
