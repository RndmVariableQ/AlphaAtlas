`lambda_l2=0`。其余参数为 50 轮、学习率 0.05、15 叶、最大深度 5、4 线程；Linear OLS。
所有已评估组合与 B26 使用同参数、同样本拟合。B26 的绝对指标如下：

ΔPearson IC 和 ΔSpearman IC 均为扩充库减去上述配对 B26；先逐品种计算全期
相关性，再按完整 Test 的 √总成交额加权。两类 IC 均使用原始目标。

（seed 20261102）。Spearman 每次抽样后在品种内重新排名，并列值取平均秩；
两种区间均固定预测和品种权重。新增 Spearman 区间覆盖 300 次主节点。

## 样本、冻结和适用范围

各 scope 均先保存模型并核验，再读取 Test，共 52 个配对模型。全部组 Train+Val 为 5,296,605 行，
Test 为 2,549,205 / 2,558,829 行，覆盖率 99.623890%。IC 使用 80 品种、
2,401,248 行；WMSE 使用 86 品种、2,429,676 加权行。
各组配对 B26 LightGBM 拟合与逐行预测一致；已有配对结果的行，其 Linear 和预处理
按 rtol=1e-12、atol=1e-15 与来源核对，旧参数产物保留。fit 在 Test 前后逐字节未变。
变换后目标复用已核验的原共同训练集统计，不使用 Test 分位点或均值。
区间为按年分层、全市场同步的 20 交易日块、2000 次重采样，固定预测不重训。

本轮使用用户指定参数，未重新搜索、选择成员或预算节点；没有模型服务调用。
此前参数试验已查看 2024–2025，本轮仍属于历史 Test 敏感性分析，不是新的盲测。
