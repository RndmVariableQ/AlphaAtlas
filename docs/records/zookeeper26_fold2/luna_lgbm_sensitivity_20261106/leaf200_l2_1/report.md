# B26 Luna 第一轮完整结果：每叶最少样本 2000 → 200

2026-11-06；固定 `lambda_l2=1`，仅将 `min_data_in_leaf` 从 2000 降至 200。
其他参数：50 轮、学习率 0.05、15 叶、深度 5、seed 42、4 线程，无 early stopping。
每叶最少样本数不是训练集总样本数；本轮每组 Train+Val 仍为 5,296,605 行。
同样使用 1%/99% 裁剪、按品种去均值；复用六次冻结搜索的因子、准入顺序及方向。

六个 300 次组合的平均加权 Pearson IC 从 0.014889916 升至 0.015362915，变化 +0.000472998。
5/6 行 IC 上升，4/6 行 WMSE 改善；各行参数变化的 IC 95% 区间均包含 0。
依照实验前说明的平均 IC 口径，第二轮采用 leaf200，继续比较 L2=1 与默认 L2=0。

## 结果解释与核验

300 次节点中，V1 的 LightGBM 绝对 IC 最高；只有 MCTS-LLM 相对 B26 的 LightGBM ΔIC
区间完全高于 0。六行 LightGBM 的 WMSE 点估计均未优于 B26，区间均包含 0。
V3 在降低叶样本数后 IC 提升最多，但参数差值区间仍包含 0，不能据此认定 2000 明显过大。

Linear 拟合、逐行预测与原参数结果精确一致。全部因子身份、预处理、训练样本保持一致，
各 scope 的配对 B26 拟合和预测一致；全部 fit 在读取 Test 前保存且 Test 前后逐字节未变。
独立 B26 fit 用于提供配置；上述比较基准以各 incremental scope 内的配对 B26 为准。

Test 共同样本 2,549,205 / 2,558,829 行，覆盖率 99.623890%。IC 固定为 B26 共同可评分
的 80 品种、2,401,248 行；WMSE 使用 86 品种、2,429,676 加权行。95% 区间采用按年分层、
全市场同步的 20 交易日块，2000 次重采样，seed 20261102；固定预测，不在重采样中重训。

2024–2025 历史 Test 已查看，本轮为参数敏感性分析。第二轮将使用这次 Test 点估计选定
的叶样本数，因此也不能作为新的盲测证据；结果不回传搜索。
