# B26 Luna：LightGBM 叶样本数与 L2 敏感性（2026-11-06）

复用原表六次冻结搜索，仅依次改变两个下游参数。第一轮固定 L2=1，比较每叶最少
2000／200 样本；按六个 300 次组合的平均加权 Pearson IC 选择 200。第二轮固定
leaf200，将 L2 从 1 改为本机 LightGBM 4.7.0 的默认值 0。

共同参数为 50 轮、学习率 0.05、最多 15 叶、最大深度 5、seed 42、4 线程；
Linear、训练预处理、冻结因子、准入顺序、方向与样本规则保持不变。

## 样本和冻结核验

每轮先保存全部 30 个配对模型，再统一读取 Test；独立 B26 基准另存两种模型。
两轮每组共同 Train+Val 均为 5,296,605 行，Test 为 2,549,205／2,558,829 行，
覆盖率 99.623890%。IC 使用 80 品种、2,401,248 行；WMSE 使用 86 品种、2,429,676 行。
因子身份、预处理、Linear 模型与逐行预测均与来源精确一致；各 scope 的 B26 拟合和
预测相同，全部 fit 在 Test 前后逐字节未变。核验明细见各轮 evaluation_audit.json。
独立 B26 fit 用于提供配置；表内基准采用各 incremental scope 内同样本拟合的配对 B26。

2024–2025 已查看，且第二轮叶样本数由第一轮历史 Test 点估计选择；两轮均属于历史
留出敏感性分析，不能作为新的盲测结论。没有新增搜索或模型服务调用，结果不回传搜索。
V3 的残差反馈、提示词和并发配置不同于旧方法，方法间比较保留原实验的边界。
